\# Contributing



\## Workflow



1\. Open an Issue.

2\. Create a branch from main: type/short-description.

3\. Make small commits, each doing one thing.

4\. Open a Pull Request that references the Issue with "Closes #N".

5\. Merge only when CI is green. No direct pushes to main.



\## Commit convention



We use Conventional Commits: type: short description.



Types: feat, fix, docs, test, chore, refactor, ci.



The commit message should explain why the change was made.
